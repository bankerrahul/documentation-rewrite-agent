## Image Optimization Guidelines

For all screenshots:

1. **Resolution:** Capture at 2x resolution for retina displays, then optimize for web
2. **Format:** Use PNG for UI screenshots with text
3. **File Size:** Optimize to keep under 200KB per image when possible
4. **Dimensions:** Maximum width of 1200px (will be responsive in documentation)
5. **Annotations:** Use red boxes/circles or arrows with 3-4px stroke width
6. **Consistency:** Use the same annotation style throughout all images
7. **Code Clarity:** For screenshots showing code, ensure syntax highlighting is visible and text is readable
