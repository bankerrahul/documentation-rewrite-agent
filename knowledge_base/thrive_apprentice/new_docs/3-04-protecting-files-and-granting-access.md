# How to Protect Files and Grant Access in Thrive Apprentice
<!-- /wp:heading -->

<!-- wp:paragraph -->
In this article, you'll learn how to use Thrive Apprentice's Protected Files feature to prevent unauthorized downloading of your course resources, PDFs, and other downloadable materials—and how to grant file access to the right students and customers.
<!-- /wp:paragraph -->

<!-- wp:heading -->
## What Are Protected Files?
<!-- /wp:heading -->

<!-- wp:paragraph -->
Protected files are downloadable resources—such as PDFs, worksheets, templates, or audio files—that are shielded from unauthorized access. Without protection, anyone who obtains a direct download link could share it freely, allowing non-paying users to access your premium materials.
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
Thrive Apprentice's Protected Files feature ensures that only users who have purchased or been granted access to a product can download the associated files. If someone without access tries to use a shared download link, they're blocked.
<!-- /wp:paragraph -->

<!-- wp:heading -->
## Protecting Files in Thrive Apprentice
<!-- /wp:heading -->

<!-- wp:paragraph -->
To set up file protection:
<!-- /wp:paragraph -->

<!-- wp:list {"ordered":true} -->
1. Navigate to **Thrive Dashboard** > **Thrive Apprentice**.
2. Click **Protected Files** in the left sidebar.
3. Click **+ Add New File** to upload a file or select one from your WordPress media library.
4. Enter a descriptive name for the file so you can easily identify it later.
5. Click **Save** to add the file to your protected files library.
<!-- /wp:list -->

<!-- wp:paragraph -->
Once a file is added to the Protected Files section, its download link is secured. Only users who meet the access requirements you define can download it.
<!-- /wp:paragraph -->

<!-- wp:heading -->
## Configuring Protected File Options
<!-- /wp:heading -->

<!-- wp:paragraph -->
Each protected file has several options you can configure:
<!-- /wp:paragraph -->

<!-- wp:list -->
- **File Name** — The display name shown to students when the file is available for download.
- **File URL** — The secured download link that Thrive Apprentice generates. This link checks the user's access status before allowing the download.
- **Access Rules** — Define which products or courses a user must have access to in order to download this file.
<!-- /wp:list -->

<!-- wp:paragraph -->
**Important:** Never share the direct media library URL of a protected file. Always use the secured download link generated by Thrive Apprentice, which enforces your access rules.
<!-- /wp:paragraph -->

<!-- wp:heading -->
## Granting File Access to Products and Courses
<!-- /wp:heading -->

<!-- wp:paragraph -->
To control who can download a protected file:
<!-- /wp:paragraph -->

<!-- wp:list {"ordered":true} -->
1. Open the protected file you want to configure.
2. In the **Access Restriction Rules** section, click **+ Add Rule**.
3. Choose the access condition:
<!-- /wp:list -->

<!-- wp:list -->
- **Product-based access** — Only users who have access to a specific product can download the file.
- **Course-based access** — Only users enrolled in a specific course can download the file.
- **Logged-in users** — Any registered and logged-in user can download the file, regardless of product ownership.
<!-- /wp:list -->

<!-- wp:list {"ordered":true,"start":4} -->
4. Select the specific product(s) or course(s) from the dropdown.
5. Click **Save** to apply the rule.
<!-- /wp:list -->

<!-- wp:paragraph -->
You can add multiple rules to a single file. For example, you might grant access to users of "Product A" and also to users of "Product B"—either condition being met will allow the download.
<!-- /wp:paragraph -->

<!-- wp:heading -->
## Adding Protected Files to Your Content
<!-- /wp:heading -->

<!-- wp:paragraph -->
After protecting a file, you need to place the download link where students can find it:
<!-- /wp:paragraph -->

<!-- wp:list -->
- **In lesson content** — Paste the secured download link directly into a lesson using a text link or button in Thrive Architect.
- **As a lesson resource** — Attach the file as a downloadable resource within the lesson settings so it appears in the lesson's resource sidebar.
- **On pages or posts** — Add the secured download link to any WordPress page or post to offer the file outside of your course structure.
<!-- /wp:list -->

<!-- wp:paragraph -->
**Tip:** When using Thrive Architect, you can add a **Button** element and set its link to the protected file's secured URL. This creates a clean, prominent download button for your students.
<!-- /wp:paragraph -->

<!-- wp:heading -->
## Managing Your Protected Files
<!-- /wp:heading -->

<!-- wp:paragraph -->
To manage your existing protected files:
<!-- /wp:paragraph -->

<!-- wp:list {"ordered":true} -->
1. Navigate to **Thrive Dashboard** > **Thrive Apprentice** > **Protected Files**.
2. Browse or search the list of files you've added.
3. Click on any file to edit its name, update the source file, or modify access rules.
4. To remove protection, delete the file entry from the Protected Files section.
<!-- /wp:list -->

<!-- wp:paragraph -->
**Note:** Deleting a file from the Protected Files section removes the access protection but does not delete the actual file from your WordPress media library.
<!-- /wp:paragraph -->

<!-- wp:heading -->
## Conclusion
<!-- /wp:heading -->

<!-- wp:paragraph -->
That's it! You've successfully learned how to protect your downloadable files, set access rules, and grant file access to specific products and courses in Thrive Apprentice. This ensures that only paying customers or enrolled students can download your premium resources.
<!-- /wp:paragraph -->
