# How to Use A/B Testing in Thrive Leads — Complete Guide

In this article, you'll learn how to run A/B tests (split tests) to optimize your opt-in forms and increase your conversion rates.

## Types of Tests

Thrive Leads allows you to run two distinct types of tests:

1. **Design Test:** Test two different variations of the *same* form type (e.g., Lightbox A vs. Lightbox B with different colors).
2. **Form Type Test:** Test two completely different form types against each other (e.g., Lightbox vs. Ribbon) to see which is more effective.

## Starting a Test

### 1. For Design Tests

1. Go to your form type (e.g., Lightbox).
2. Click the **Clone** icon on your existing form to create a copy.
3. Edit the design of the copy (change the headline, button color, etc.).
4. Click **Start A/B Test**.
5. Give your test a name and start it.

### 2. For Form Type Tests

1. Go to your **Lead Group**.
2. Ensure you have at least two active form types (e.g., add a Lightbox and a Widget).
3. Click **Test Types of Forms Against Each Other**.
4. Select the forms you want to include in the test.

## Automatic Winner Settings

You can let Thrive Leads run the test and automatically choose the winner based on data.

1. In the test configuration popup, enable **Automatic Winner Settings**.
2. Set your conditions:
    * **Minimum Conversions:** The minimum number of signups required before a decision is made (e.g., 100).
    * **Minimum Duration:** How long the test must run (e.g., 14 days).
    * **Chance to Beat Original:** The statistical certainty required (e.g., 95%).
3. If enabled, Thrive Leads will automatically stop the losing form and show only the winner once these criteria are met.

## Manual Winner Selection

If you prefer to make the call yourself:

1. Let the test run until you have enough data.
2. Click **View Test** in the dashboard to see the performance graph.
3. When you're satisfied, click **Stop Test and Choose Winner**.
4. Select the form you want to keep. All others will be archived.

That's it! You are now ready to optimize your campaigns with data-driven testing.
