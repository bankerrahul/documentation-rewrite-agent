# OptinMonster Public Documentation SOP Summary

## 1. Purpose

* **Empower Users:** Provide clear, accurate info to help users succeed independently.
* **Reduce Support:** Deflect common tickets with high-quality self-help resources.
* **Consistency:** Maintain a unified voice and standard across all docs.

## 2. Workflow

1. **Request:** New docs/updates are requested (likely via internal tracker).
2. **Drafting:** Author writes content following the **Style Guide**.
    * Focus on clarity and user needs.
    * Include relevant media (images/videos).
    * Audit legacy articles for any existing videos and incorporate them into the draft.
3. **Review:** Peer or Lead review for:
    * Accuracy & Completeness.
    * Style Guide adherence.
    * SEO best practices.
4. **Revision:** Author fixes issues based on feedback.
5. **Publishing:** Approved content is pushed live.

## 3. SEO Requirements

* **Keywords:** Use relevant keywords in titles, headers, and body.
* **Meta Description:** Write clear, compelling summaries for search results.
* **Images:** Add Alt Text and optimize file sizes.
* **Linking:** Use internal links to related docs and external links where helpful.
