# OptinMonster Documentation Master Guide

This guide consolidates the rules and best practices from the Style Guide, SOP, Content Guide, and Transitions Cheatsheet. Use this as the primary reference for all documentation work.

---

## 1. Tone & Voice

* **Friendly & Helpful:** Write as if you are helping a friend. Be conversational but professional.
* **User-Centric:** Address the user as "**you**". Focus on their goals and solving their problems.
* **Concise:** Avoid unnecessary jargon. Focus on "how-to" steps rather than deep technical theory.

## 2. Formatting Rules

* **UI Elements:** Always **bold** text that appears in the UI (buttons, labels, tabs, menu items).
  * *Example:* Click **Save**. Go to **Settings** > **General**.
* **Title (H1):** Rewrite the title to be action-oriented. Start with "**How to**" whenever possible.
* **Headings:** Use **Title Case** for all headings (H1, H2, H3). Structure content logically.
* **Lists:**
  * Use **Numbered Lists** for sequential steps.
  * Use **Bulleted Lists** for options or non-sequential items.
* **Alerts:** Use distinct formatting for **Note:**, **Tip:**, **Important:**, and **Warning:**.

## 3. Grammar & Mechanics

* **Capitalization:**
  * Match UI capitalization exactly (e.g., "Display Rules", not "display rules").
  * Always capitalize **OptinMonster**.
* **Punctuation:**
  * **Oxford Comma:** Required (e.g., "A, B, and C").
  * **Em Dashes (—):** Use for breaks in thought (no spaces around them).
* **Spelling:** Use **American English** (e.g., "color", "optimize").

## 4. Terminology & Word Usage

| Do Use | Don't Use |
| :--- | :--- |
| **log in** (verb) | login (as verb) |
| **website** | web site, web-site |
| **e-commerce** | ecommerce |
| **email** | e-mail |
| **campaign** | popup, form (unless specific) |

## 5. Standard Transitions (Snippets)

### Introductions

* "In this article, you'll learn how to..."
* "This guide will walk you through..."
* "Before you begin, make sure you have..."

### Steps

* "Next, you'll need to..."
* "Once you've done that, the next step is to..."
* "Now that you have [action], you can..."

### Conclusions

* "That's it! You've successfully..."
* "You now know how to..."
* "If you're still having trouble, check out..."

### Related Resources

* **Relevance:** Links must be directly related to the topic (no generic links).
* **KB Link:** Always include a link to the specific product's Knowledge Base category.
  * *Example:* **Thrive Quiz Builder Documentation:** Explore the full [Thrive Quiz Builder knowledge base](URL).
* Format: `* **[Topic]:** [Link Title](URL)`

## 6. Workflow & SEO (SOP)

* **Process:** Draft → Review (Peer/Lead) → Revision → Publish.
* **SEO Requirements:**
  * Include relevant keywords in Title, H1, and body.
  * Write a compelling **Meta Description**.
  * Add **Alt Text** to all images.
  * Add **Alt Text** to all images.
  * Use internal links to related docs.
* **Link Checking:** Verify all links are functional.
* **Video Content:** Audit the legacy article for any embedded YouTube or Wistia videos and incorporate them into the new draft.

## 7. Deliverables

For every rewrite, produce:

1. **Rewritten Doc** (`rewritten_doc.md`)
2. **Image Mapping** (`image_mapping.md`)
3. **Review Report** (`review.md`)
