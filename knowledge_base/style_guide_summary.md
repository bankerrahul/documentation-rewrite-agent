# OptinMonster Style Guide Summary

## 1. Tone and Voice

* **Friendly & Helpful:** Maintain a conversational, approachable tone.
* **Concise & Clear:** Be thorough but avoid overwhelming technical jargon. Focus on "how-to" for docs.
* **User-Centric:** Address the user directly ("you") and focus on their goals.

## 2. Formatting

* **Bolding:** Use for UI elements users interact with (e.g., **Save**, **Settings**, **Field Name**). Also for prefixes like **Note:**, **Important:**.
* **Italics:** Use sparingly for emphasis.
* **Lists:**
  * Numbered lists for sequential steps.
  * Bulleted lists for options or non-sequential items.
* **Headers:** Use H2, H3, etc., to structure content logically.
* **Alerts:** Use blockquotes or distinct formatting for **Note:**, **Tip:**, **Warning:**.

## 3. Terminology

* **Consistency:** Use exact product names as they appear in the UI.
* **Navigation:** Use ">" or clear text for paths (e.g., **Settings** > **General**).

## 4. Images & Screenshots

* **Relevance:** Ensure images are current and directly support the text.
* **Annotation:** Highlight key areas with boxes or arrows.
* **Optimization:** Optimize for web performance.
* **Videos:** Check for and include relevant YouTube/Wistia videos from original documentation.
