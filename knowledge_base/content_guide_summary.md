# OptinMonster Content Guide Summary

## 1. Grammar & Mechanics
*   **Capitalization:**
    *   **Title Case** for all headings (H1-H6).
    *   **UI Elements:** Match exact capitalization in the app (e.g., "Save", "Display Rules").
    *   **Brand:** Always "OptinMonster".
*   **Punctuation:**
    *   **Oxford Comma:** Required (e.g., "A, B, and C").
    *   **Em Dashes (—):** Preferred for breaks, no spaces around them.
    *   **Lists:** Consistent end punctuation (all periods or none).

## 2. Word Usage
*   **Preferred Terms:**
    *   **"log in"** (verb) vs **"login"** (noun/adj).
    *   **"website"** (one word).
    *   **"e-commerce"** (with hyphen).
    *   **"email"** (no hyphen).
    *   **"campaign"** for OptinMonster units.
    *   **"you"** to address the user.
*   **Spelling:** American English (e.g., "color", "optimize").

## 3. Formatting
*   **Dates:** "Month Day, Year" (e.g., January 1, 2025).
*   **Numbers:**
    *   Spell out **one** through **nine**.
    *   Use numerals for **10+** or technical specs/measurements.

## 4. Cheatsheet Rules
*   **Consistency:** Stick to the defined formats throughout.
*   **UI Names:** Never paraphrase UI labels; use exact text.
